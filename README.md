  Descripción del proyecto
eightClimb es una plataforma web creada por estudiantes de Eight Academy con el objetivo de facilitar el acceso a información sobre escalada. La página reúne en un solo lugar rutas, recomendaciones de seguridad, guías para principiantes y espacios para conectar con la comunidad de escaladores.
El proyecto nació al identificar que muchas personas interesadas en este deporte no saben dónde practicar, qué medidas de seguridad tomar o dónde encontrar información confiable.
 Problema
Actualmente, la información sobre escalada está dispersa entre redes sociales, páginas web y diferentes aplicaciones. Esto dificulta que jóvenes y principiantes encuentren lugares seguros para practicar o aprendan cómo iniciarse correctamente en este deporte.
 Solución
Creamos eightClimb, una plataforma web sencilla y accesible que permite a los usuarios:
Encontrar rutas y lugares para escalar.
Consultar niveles de dificultad.
Aprender técnicas básicas y consejos de seguridad.
Conectarse con otros miembros de la comunidad.
Acceder a información organizada desde cualquier dispositivo.
 Objetivo General
Desarrollar una plataforma digital que centralice información sobre escalada para ayudar a jóvenes y principiantes a practicar este deporte de manera segura, organizada y accesible, promoviendo la actividad física y el aprendizaje.
¿Cómo funciona?
El usuario ingresa a la página web y encuentra tres secciones principales:
 Mapa de rutas
Permite conocer lugares para escalar y su nivel de dificultad.
 Guías y seguridad
Incluye recomendaciones, técnicas básicas y consejos para principiantes.
 Comunidad
Espacio para compartir experiencias, recomendaciones y fomentar el crecimiento del deporte.

Objetivos de Desarrollo Sostenible (ODS)
ODS 3: Salud y Bienestar
Promovemos la actividad física y hábitos de vida saludables mediante la práctica responsable de la escalada.
ODS 4: Educación de Calidad
Facilitamos el acceso a conocimientos sobre técnicas y seguridad en este deporte de manera gratuita y accesible.
Relación con Eight Academy
Nuestro proyecto nace en Eight Academy, uno de los pocos colegios de Quito que cuenta con un muro de escalada. Esta experiencia nos permitió identificar necesidades reales de quienes practican este deporte y diseñar una solución útil para la comunidad.
 Impacto esperado
Buscamos que más personas descubran la escalada, pierdan el miedo a comenzar y tengan acceso a información confiable para practicar de forma segura. Además, queremos fortalecer la comunidad de escaladores y promover estilos de vida activos.
